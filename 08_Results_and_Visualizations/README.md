# 📊 Results & Visualizations

This directory serves as the central storage location for all final experimental results, figures, evaluation reports, and project presentations. It consolidates the outputs from the machine learning and signal processing pipelines.

## Pipeline Integration
This folder is the final destination for artifacts generated by the ML training and evaluation steps, providing a clean separation between source code and experimental outputs.

## 📁 Directory Structure

- `figures/`: PNG and SVG images of evaluation plots (e.g., Clarke Error Grid, Loss Curves).
- `reports/`: PDF and Markdown documents detailing model performance and clinical validity.
- `presentations/`: PowerPoint and PDF slide decks summarizing the project findings.
- `tables/`: CSV and Excel files containing raw prediction data, error analysis, and evaluation metrics.
- `tuning_history.csv`: Historical log of hyperparameter tuning runs and their resulting MAE/RMSE scores.

## 🚀 Quick Start

This is primarily a storage directory. No scripts are executed directly from here. 
- To generate new results, run the pipeline from the `08_Machine_Learning_Models` directory.
- Review `tuning_history.csv` to track the progression of model optimizations across the 17 recorded experimental runs.
